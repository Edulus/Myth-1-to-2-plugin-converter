For Keep

The monster settings TFL never had

An answer to Keep's question in Bagrada chat: which settings, and what does “Magma's own version of each unit” mean?

Which settings

Only one tag: the mons (monster) tag. Myth II's mons tag has 17 fields that The Fallen Lords' does not have at all. Every other field is copied from the unit's own TFL value. For these 17 the converter has nothing to copy, so it has to choose a value. It chose one value for every unit: the most common one in Project Magma's port of The Fallen Lords.

Checked against Magma's port, unit by unit: 15 of the 17 are the same for every unit (mana, berserk, artifacts carried, experience, propulsion, map action, hack flags and so on), and our value already matches Magma's for all 39 units it ported. Only two differ from unit to unit:

  • pathfinding radius: how much room the unit needs when finding its way around others. We gave every unit 77; Magma's values run from 51 to 220.
  • more hack flags: not documented anywhere we have found. 0, 50, 90 or 100 in Magma.

Magma's own version of each unit

For a thrall, copy what Magma gave its thrall; for a trow, Magma's trow; and so on, instead of one value for all. Since version 0.15 the converter does that, choosing by the sprites the unit is drawn with, so a plugin's own unit built on thrall sprites gets the thrall's values.

Two units stand out: the Forest Giant (220 in Magma, 77 from us before) and the trow (154 and 90, against 77 and 0). They are the two Keep found would not attack. A big unit given a small unit's room may be the reason; that is a guess until someone tests 0.15.
