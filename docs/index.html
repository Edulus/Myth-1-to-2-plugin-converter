Get started — public beta

Convert a Myth: The Fallen Lords plugin for Myth II: Soulblighter. The easiest way is the in-browser converter. The command-line steps below are for those who want more control; no Python packages need installing.

You need: Myth II 1.8.5, Python 3.12 or later, a TFL plugin (.gor), and your own TFL game's tags folder containing TAGS.GOR and ARTSOUND.GOR. Game files are not included.

  1. Download and unzip. Open the repository and choose Code → Download ZIP, then extract it. There is no packaged release yet. With Git, you can instead run: 
    git clone https://github.com/Edulus/Myth-1-to-2-plugin-converter.git
cd Myth-1-to-2-plugin-converter
  2. Set up Python. On Windows, double-click launch.bat in the extracted folder. It looks for Python 3.12+ and attempts to install it with winget if missing; follow its instructions and run it again after installation. If winget is unavailable, it opens the Python download page. On other systems, install Python 3.12+ first.

    The launcher opens the guided browser app. That app cannot build the stock tagset yet. Use a terminal for the next two steps. On Windows, open the extracted folder in File Explorer, type powershell into its address bar and press Enter. Commands must run in the folder containing launch.bat and src. Close Myth II before writing plugins.

  3. Build the stock tagset once. Replace every example path with your own, keeping the quotes. Use python3 instead of python if that is your Python 3.12+ command; on Windows, py -3.12 is another option. 
    python -m src tagset --in "TFL/tags/TAGS.GOR" --in "TFL/tags/ARTSOUND.GOR" --out "Myth II/plugins/ZZ TFL stock"

    This supplies the original game's tags that community plugins depend on. The output is a file with no extension, inside your Myth II plugins folder.

  4. Convert a plugin. Extract the plugin's ZIP first, then point at its .gor file: 
    python -m src convert --in "Sir Mauriac's Tale.gor" --out "Myth II/plugins/ZZ Mauriac"

    Shortcut: add --stock "TFL/tags/TAGS.GOR" --stock "TFL/tags/ARTSOUND.GOR" to this command and the stock tags are built into the converted plugin. You can then skip step 3 and the tagset choice in step 5. The file is much larger, and it is the form to share. Only share a plugin whose author agrees.

    No decisions file is required for this baseline workflow. Conversion warnings identify unsupported content; producing a file does not guarantee that every level will play.

  5. Play in Myth II. Start the game → New Game → choose the converted campaign → Tagsets → activate ZZ TFL stock → pick a level → OK. Choose the tagset after the campaign, because changing campaigns can clear the selection.

Before you test

  • Quit Myth II before converting or replacing plugin files; the game holds them open. Restart after adding files.
  • Keep output filenames at most 32 characters. The internal plugin name defaults to that filename; use distinct names so plugins do not hide each other.
  • The stock tagset replaces same-ID Myth II tags while active. Activate it only for converted TFL levels.
  • Only one campaign can load at a time. The stock tagset contains no selectable levels, so it can load alongside your converted campaign.
  • If writing to the install folder fails, write to a folder you can access and copy the finished files into Myth II's plugins folder while the game is closed.

Optional guided app: run python -m src studio or double-click launch.bat. It can preview and convert an individual plugin and read the game log. Build the stock tagset with the command above first. Its missing-reference suggestions are not a check against the complete stock tagset; the command-line route above is the tested starting point.

What works — and what needs testing

Two levels have reached the end-game screen in Myth II 1.8.5: Tandem and In the Name of Glory from Sir Mauriac's Tale. This is a beta, not a claim that every TFL plugin works.

  • Converts terrain, markers, map actions, monsters and units, objects, projectiles, artifacts, scenery, weather, mesh effects, lighting, sprite collections and text.
  • Building models (mode/geom) are measured but not converted. Lighting uses standard values for every map. Terrain is redrawn on Myth II's finer grid, with heights blended between the original points.
  • Sounds, collection references, projectile groups and other unsupported bodies are copied unchanged and reported. Other levels and multiplayer remain unverified.

Help test or report a problem

Every visitor can help. Try a level you know and report what differs from TFL. Open a question or progress update below and use its comment box: a name, message and one-word Myth check — no account or sign-in.

Include the plugin and level names, Myth II version, what you expected, what happened, and the final lines of myth_log.txt from the Myth II folder. For a crash, include relevant lines from the newest myth_crashlog- <date>.txt. Check that the log lists both your campaign and stock tagset after Starting mesh. Share logs and observations, not game files; remove private paths if needed.

Code contributions are welcome through GitHub; the README and format notes describe current support and research.
