Convert a plugin

Turn a Myth: The Fallen Lords plugin into one that Myth II: Soulblighter 1.8.5 can play. It runs entirely in this browser tab: your file is not uploaded anywhere.

Good to know

  • Use a computer, not a phone. Converting needs a lot of memory; close other tabs if it fails.
  • The first time, the page fetches the original Fallen Lords game files (320 MB) from this website. Your browser keeps them for next time.
  • The converted plugin carries the original game files it needs, so you don't need anything else installed.
  • Beta. Tested with Sir Mauriac's Tale on Windows. Other plugins may convert with parts missing, and the report tells you what it could not convert.
  • Only share a converted plugin if its author agrees.
