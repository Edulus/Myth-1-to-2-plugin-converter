    Converting a Fallen Lords map to Soulblighter

    Myth: The Fallen Lords and Myth II: Soulblighter store their content the same broad way, but not identically. A map made for the first game will not load in the second. This walks you through what has to change and what you have to decide.

    The one idea you need first

    Both games keep everything — maps, units, sounds, artwork, text — in numbered pieces called tags. A tag has a four-character id like mawa and a type like mesh (a map) or mons (a monster). A plugin is just a container holding a pile of tags.

    Converting means rewriting each tag into the shape Soulblighter expects, then packing them into a Soulblighter container. Some tags translate cleanly. Some have no equivalent and need a decision from you. That is what this tool is for.

    Step 1 · Your two ingredients

    You need the map you want to convert, and a copy of Soulblighter.

    The Fallen Lords plugin

    Usually a .gor file, or a file with no extension, from a Fallen Lords plugins folder.

    Your Myth II install

    The folder containing tags and plugins. Needed for two reasons: to see which tags Soulblighter already has, and to install the finished plugin.

    Step 2 · What is inside your plugin

    Here is what we found, and what it means.

    Reading that list

    mesh tags are the maps themselves — one per playable level. .256 are collections of artwork, mons are monsters, stli and text hold the words you read in-game.

    Converted means we rewrote that tag into Soulblighter's format. Copied as-is means we do not know how to translate it yet, so it goes across untouched — which for most types means the game will not understand it. Nothing is silently faked.

    Step 3 · The catch nobody warns you about

    A Fallen Lords plugin is not self-contained. It leans on the original game's built-in library — the standard water, wind, lighting, ambient sounds every map uses. Those tags live in Fallen Lords itself, not in the plugin.

    Soulblighter does not have them. So a converted plugin points at things that are not there, and the level fails to load.

    Two ways out

    Substitute. Pick the closest Soulblighter tag instead. Quick, and good enough for things like water or lighting where an approximation is fine. You do that on the next step.

    Supply the originals. Load a converted Fallen Lords tagset alongside your plugin — a plugin containing the original library, already converted by someone else. More faithful.

    A tagset is just a plugin with no maps in it. Soulblighter only offers a plugin as a tagset if it contains no levels, which is why a converted Fallen Lords campaign cannot be used as one directly.

    Step 5 · Convert and install

    Naming it

    Keep the file name under 32 characters. Soulblighter silently ignores plugins with longer names — no error, the plugin simply never appears.

    Step 6 · Try it, and read the failure

    Loading it

    1. Quit Soulblighter if it is running — it reads plugins at startup.
    2. Start it, choose New Game.
    3. Find your plugin in the Campaign list on the left.
    4. Pick a level, then OK.

    If you converted a tagset too, add it with the Tagsets button before picking a level.

    When it fails — and it will, for now

    Soulblighter keeps a log at myth_log.txt in its folder, and it is specific about what went wrong. Two you are likely to see:

    couldn't read header for media definition 'xxxx'
    A tag the map needs is missing. Substitute it, or load a tagset that has it.
    EXCEPTION_ACCESS_VIOLATION in byte_swap_data
    The map's internal data is still in Fallen Lords shape. Nothing you can fix from here — this is the part of the converter still being built.
